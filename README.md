# .github

Organization profile and default community health files for **Urbiva**.

| Path | Purpose |
| --- | --- |
| `profile/README.md` | The public organization profile |
| `profile/assets/` | Public brand images used by the profile |
| `ISSUE_TEMPLATE/` | Default issue forms |
| `PULL_REQUEST_TEMPLATE.md` | Default pull request template |
| `CONTRIBUTING.md`, `SECURITY.md` | Default contribution and security policies |

This repository is public. Only add material that is safe to publish: no credentials, internal architecture details, datasets or unreleased work.
