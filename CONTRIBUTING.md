# Contributing to Urbiva

Thank you for helping make cities work for everyone.

## Workflow

1. Branch from `main`: `feat/*`, `fix/*`, `docs/*` or `chore/*`.
2. Keep pull requests small and focused.
3. Run the checks described in each repository's README.
4. Open a pull request using the template; at least one review is required.

## Rules we keep

- AI output is an estimate until a person confirms it.
- Sample data is always labelled as sample data.
- Never commit secrets, `.env` files, personal data or unlicensed assets.
- Never present planned research as implemented or report results that were not measured.
- Write in plain language and add alt text to every image.
