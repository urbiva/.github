# Support

| Need | Where |
| --- | --- |
| Report a bug | Open an issue with the bug report form in the affected repository |
| Suggest an improvement | Open an issue with the feature request form |
| Security vulnerability | Use private vulnerability reporting; see [SECURITY.md](SECURITY.md) |
| Permission beyond the license, partnerships, press | Contact the organization owners through GitHub |
| Legal notice | Open an issue in this repository titled "Legal notice: ..." without confidential or personal data (License, Section 17) |

Please do not include personal data, credentials or photos of identifiable people in any request.
